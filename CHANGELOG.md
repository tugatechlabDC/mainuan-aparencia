# Changelog

Todas as alterações relevantes deste projeto são registadas neste ficheiro.

O formato segue o [Keep a Changelog](https://keepachangelog.com/pt-PT/1.1.0/).

## 🎉 Lançamento --> [1.1.1] - 2026-11-19

### Adicionado
- Repositório no GitHub com README, CHANGELOG, licença e screenshots.

### Estado da versão
- Tema claro/escuro com o wallpaper Mainuan correspondente.
- Seis cores de destaque, com esquema de cores e ícones a acompanharem.
- Nove layouts de desktop, incluindo os estilos macOS e Windows 11.
- Gestão de wallpapers.
- Interface em português (PT), português (BR), inglês, francês e espanhol.

## [1.1] - 2026-11-12

### Adicionado
- Nova página Sobre.
- Barra lateral só com ícones por defeito, com botão para expandir.
- Novo ícone da aplicação (mesmas cores).
- Traduções em português (PT), português (BR), francês, espanhol e inglês, escolhidas automaticamente pela língua do sistema.

### Alterado
- O título da janela já não repete o nome da aplicação.

### Corrigido
- Mudança de tema: aceita o esquema de cores pelo id ou pelo nome, aplica-o manualmente quando o `plasma-apply-colorscheme` não o faz e aplica sempre o wallpaper Mainuan_B/Mainuan_C do modo escolhido.
- Validação do layout macOS: espera que o Plasma construa os painéis, tolera alturas arredondadas e indica a verificação que falhou.

### Removido
- Layout GNOME.

## [1.0] - 2026-11-12

### Adicionado
- Primeira versão.
